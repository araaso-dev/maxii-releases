# Maxii

Downloads for **Maxii**, a native macOS menu bar app: live system stats, display controls, per-app audio, a window
switcher and keyboard remapping.

**[Download the latest version](https://github.com/araaso-dev/maxii-releases/releases/latest)**: open the `.dmg`
and drag Maxii to Applications.

- macOS 14.2 or later, Apple silicon
- Signed with a Developer ID and notarized by Apple

This repository only holds the release downloads. Copies installed from the DMG don't update themselves, so check
back here for new versions.
